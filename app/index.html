WHY BLUE-GREEN

The standby always runs the next release

New code ships to whichever environment isn't taking traffic. It gets its own health checks and smoke tests before the router ever points a single request at it — production stays untouched until the new version has proven itself.

ROLLBACK

Reverting is a router change, not a redeploy

If health checks fail after cutover, traffic flips back to the previous environment immediately. No redeploy, no rebuild — just a switch back to the version that was already working.
